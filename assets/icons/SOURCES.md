# Hero social icons

- `github.svg`: GitHub mark from [GitHub Primer Octicons](https://github.com/primer/octicons/blob/main/icons/mark-github-16.svg). MIT license in `OCTICONS-LICENSE.txt`.
- `linkedin.svg`: LinkedIn brand icon from [Bootstrap Icons](https://github.com/twbs/icons/blob/main/icons/linkedin.svg).
- `email.svg`: envelope from [Bootstrap Icons](https://github.com/twbs/icons/blob/main/icons/envelope.svg). Both Bootstrap assets use the MIT license in `BOOTSTRAP-ICONS-LICENSE.txt`.

The original vector paths are embedded in the homepage so their color follows the existing navy/burgundy styles. No icon framework is loaded. Brand marks identify the profile destinations and do not imply endorsement.
