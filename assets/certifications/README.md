# Homepage credential artwork

`sources.json` records the original artwork URL and, for CompTIA badges, the exact public credential page already present in the verified resume data.

The six CompTIA images are genuine badge artwork retrieved from those public Credly pages. Transparent outer padding was removed and the images were resized to 160px wide for compact, sharp display. The badge artwork itself was not recreated or recolored.

`ec-council-issuer.webp` is EC-Council's official issuer logo from its own website. It is **not a credential-specific CEH badge**. It is labeled as an issuer logo and displayed beside the exact verified credential name and issuer. A personal credential badge can be supplied from the holder's Aspen account later; see [EC-Council's badge-download guidance](https://eccouncil.zendesk.com/hc/en-us/articles/205684619-Can-I-Download-the-EC-Council-Certification-Logo).

Artwork identifies documented credentials; it is not an endorsement. Homepage order is CEH first; the original resume certification data and order are unchanged.
